# Codificação para Back-End

## 🎯 Objetivos do Curso
Desenvolver habilidades e competências na construção de APIs, implementação de regras de negócio, autenticação e manipulação de bancos de dados para aplicações web.

## 🛠️ Tecnologias Aplicadas
- **Linguagem de Programação:** Node.js / JavaScript
- **Framework Web:** Express.js
- **Banco de Dados:** PostgreSQL / SQLite
- **Autenticação & Segurança:** JWT (JSON Web Tokens), bcrypt

## 🧰 Ferramentas Utilizadas
- **Ambiente de Desenvolvimento:** Visual Studio Code
- **Testes de API:** Postman / Insomnia
- **Versionamento de Código:** Git e GitHub
